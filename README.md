# Physics Sensor Position Simulation

A Python project for an academic physics exercise, modeling the position function of a sensor over time.

## Exercise Document
You can view or download the original exercise statement here:
📄 [Download/View Exercise PDF](./exercise.pdf)

## Project Overview
This project calculates and visualizes the position of a sensor based on specific time conditions from 0 to 5 seconds.

## Key Features
- Piecewise calculations using custom Python logic.
- Interactive input to test specific time steps or checkpoints.
- Clean graphical plotting using Matplotlib and NumPy.

## Results
- x(0) = 0 m
- x(1) = 2 m
- x(2) = 0 m
- x(3) = 2 m
- x(5) = 6 m

## Tech Stack
- Python 3
- NumPy
- Matplotlib
